# HR / GA Cross-Domain Matrix

Status: **NEEDS CONTRACT / NEEDS DECISION**. HR menampilkan projection lintas domain secara terbatas dan tidak mengambil alih authority.

| Domain | HR/GA dapat melihat | HR/GA tidak boleh mengubah |
|---|---|---|
| Strategy | target yang diberikan untuk konteks SDM | target korporat dan RKAP |
| Finance | status kompensasi/payroll bila authorized | pembayaran, settlement, pajak, rekening, financial actual |
| Legal | dokumen/kepatuhan SDM sesuai akses | validitas kontrak, izin, perkara, legal conclusion |
| IT | readiness akses kerja | akun, role, credential, access grant/revoke |
| Sales | kebutuhan organisasi bila disetujui | lead, pipeline, booking, closing |
| Property | kebutuhan tenaga kerja | progres fisik, quantity, RAB teknis |
| Shared Work | Project, Task, Approval, Document, Report, Finding | authority entity universal |

Tidak ada HRProject, HRTask, HRDocument, HRFinding, atau HR ARA. HR dan GA tidak memutuskan classification, retention, self-approval, atau lifecycle lintas domain dari frontend.
