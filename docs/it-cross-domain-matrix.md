# IT Cross-Domain Matrix

| Area | Authority | IT responsibility | IT boundary |
| --- | --- | --- | --- |
| Employee/person | HR | consume reference when available | no duplicate employee master |
| Workspace membership | Identity/Backend governance | request/review/provision readiness | no automatic additional workspace |
| Role/permission | Backend catalog/governance | select allowed catalog value | no self-assigned privileged role |
| Payroll/payment | Finance | no write authority | payment, settlement, reconciliation remain Finance |
| Contract/legal validity | Legal | no write authority | Legal owns validity and signatures |
| Project/task/document/finding | Shared Work | reuse universal routes | no IT-specific duplicate entity |
| ARA | ARA universal | provide workspace context | ARA is not IT authority |
| Access execution | Identity/Backend | operate only canonical approved actions | no password/token handling in UI |
| Joiner/mover/leaver | HR + IT + Identity | readiness and governed handoff | no silent provisioning/revocation |
| Session | shared session service | show authorized metadata only | secrets and tokens never visible |

Status: NEEDS CONTRACT / NEEDS BACKEND where the source or approval flow is not available.
